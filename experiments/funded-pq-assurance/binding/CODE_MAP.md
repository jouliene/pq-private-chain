## Exact review boundary

The reviewed source states that the four-word funded hash starts from a
width-12 state, absorbs eight field words per permutation and returns four
words. Parent nodes absorb sixteen untagged child words, and sorted siblings
do not bind chronological order. C adds exact depth and occupied-child checks
without changing that hash. These facts come from
[`funded-membership/REFERENCE.md`](../../funded-membership/REFERENCE.md), the
independent numerical implementation, the pinned Qnero source manifest and the
C patch. The upstream source link is
[`qnero-circuit` at f04c913](https://github.com/DigitalGuards/qnero/tree/f04c91307837c0231668383bec76ba98d89d2652/crates/qnero-circuit/src).
