# The funded Goldilocks relation in the toolkit ring

The toolkit's example hashes public keys in a binary tree using its own ring arithmetic. A live payment instead uses the registered Goldilocks note commitment, two private quaternary membership paths, two nullifiers and monetary constraints. The 34-word signed leg also binds its authorization data. Replacing its membership check with the example would disconnect the spent notes from the ledger. We priced the complete existing relation in the toolkit ring, without adding a second proof of membership or changing the funded-note format.

## Integer correspondence

Start from the existing verifier-owned 31- or 34-word statement, the pinned Poseidon2 constants and the fixed degree-seven circuit. Recompute every public coefficient from canonical network fields. Let p = 2⁶⁴ − 2³² + 1 and q = 2³⁸ − 107. For an unsigned integer u write W(u) = Σ bit(u,j) Xʲ. Integer evaluation at X=2 recovers u; reduction of a Goldilocks field element directly modulo q would not preserve multiplication. The proof ring is (Z/qZ)[X]/(X²⁵⁶+1). All private coefficient vectors in this design are constrained BIN.

* Each private field word v has two 64-bit polynomials for v and p−1−v, plus a 63-bit carry for their sum. A full ring equation W(v) + W(p−1−v) − W(p−1) + (X−2)C = 0 enforces canonicality, including the last carry.
* Each nontrivial affine input to a product is materialized once. Constants and canonical public words are verifier operands. A seventh power uses x², x⁴, x⁶ and x⁷; each temporary is a canonical residue. For a modular equation the exact integer numerator equals pk plus its result. Bound k from the maximum possible numerator. In the ring, enforce F − W(p)W(k) − W(result) + (X−2)H = 0. H has bounded signed coefficients represented by binary planes with a public bias. A private-by-private product contributes one actual rank-one quadratic term. Products with a known operand are linear.
* Constrain every unused bit to zero. For the forbidden positions j > 0, the coefficient of X⁰ in a binary vector times −Σ X^(256−j) is the sum of those positions. Include the unit constant if position zero is also forbidden. Each constant-term row covers at most 1,024 vectors. Its total lies between zero and 262,144, below q. A zero sum thus forces each forbidden position to zero.
* The generator bounds coefficient height, quotient width, signed carry range and convolution length for each shape. No multiplication in a full equality reaches degree 256. Every allowed integer coefficient residual has magnitude below q. Consequently the checked full ring equations lift coefficientwise to integers; evaluating at 2 eliminates H and recovers the original field equation. The forward witness recursion divides an even residual by 2 at each position and requires zero terminal carry. These are arithmetic correspondence arguments conditional on the proof system enforcing the binary, full-ring and constant-term checks. They do not establish an extractor for the proof system.

The reference exercise uses the actual selected branch, private witness, registered proof verifier and ordered ciphertexts in an isolated wallet. Both active membership paths, orientation, dummy/real rules, one-hot child selection and common active depth of at most 20, conservation, fee bounds, output commitments, input authority, domain separation and nullifiers still come from the funded builder. An authenticated node checks block identity, public root/count context, anchor eligibility and the shared current spent set; the ring equality alone does not implement admission. The funded circuit authenticates the ordered children via the selected root; its secret child selections in sorted groups do not directly encode a numerical append index. The envelope checks ciphertext digest and each recipient checks the decrypted note before authorizing a swap. Both owner signatures cover the same two complete frames, network, fee payer and expiry. The last three rows follow from this concrete lowering and pinned C implementation; they are not measured peak RSS or limits on all lattice provers. Let V be the number of length-one vectors, P the number of private products, E the number of full rows and S the support row count. A width-tracked vector entry allocates 3,080 B (six 512 B CRT polynomials and an eight-byte width). The output statement's dense aggregate, P active challenges and left/right reduction constraints allocate at least 3,080(V+7P). The source full rows and copied linear full rows each have an explicit constant polynomial, adding 3,080(2E−P). Every binary vector in this lowering has at least one forbidden position. The input S constant-term rows and their deep copies add 2 × 3,080(V+S) for coefficients and constants. All three populations coexist during construction of the reduced statement. The prover also keeps its input/copy, the binary sigma storage and the forward-transformed input, adding at least (3 × 512 + 3,080)V. The original statement's full linear coefficient arrays, commitment key, most metadata, later recursion and concurrent consensus work are excluded. The direct Python-to-C constructor additionally rebuilds a V-element offset array for every row, writing 1.87/1.98 decimal TB during setup on x86-64. Immutable offsets could be cached by a different implementation. ## Reproduction

The top-level reproduction checks all shape counts and negative controls using public constants. To run the actual native selector after the [toolkit build](../lazer/README.md), execute the following from the repository root. On an AVX-512 host, omit the final emulator argument.

~~~sh
bash experiments/lattice-spend/funded/price.sh "$build" "$sde64" | cmp - experiments/lattice-spend/funded/PLAN.txt
~~~

For four fresh released proofs on private disposable funds, follow the [funding and isolated capture setup](../../packed-tcith/encoding/README.md#reproduce-with-private-disposable-funds), then run the following. The released launcher keeps one spending seed per namespace and per-role private data out of logs. The additional oracle checks every coefficient against that role's real assignment before exporting only status.

~~~sh
python3 -IB experiments/lattice-spend/funded/roles.py "$work/lab" "$work/capture" "$constants" | cmp - experiments/lattice-spend/funded/ROLES.json
~~~
