## What the clean run established

The reviewer anonymously fetched the preceding tagged release `f1a513207f73ee84c3034938a00dba1d68cd7b3b`, then ran the existing native-currency PoW walkthrough with new issuers, notes, wallet keys and backups. New target directories produced the WHIR executable, both pinned matrices and both witness-capture roles. The successful four-proof run used clean public revision `ad0998099afae89ec544640f6fda6af5fd14e1d6` and took 72.27 seconds. The Rust programs and matrix generator were identical to the independently built public revision `98bed4230b988ead25841b73d9ca23afdb80dcaa`. [Build inputs and run](../wallet/README.md)

The first independent run found an adapter defect. A native-only ordinary payment gave token change of zero, but the test adapter requested a nonzero asset tag when checking the private receipt. The earlier author's deployment had normalized this tag implicitly. The corrected adapter explicitly supplies zero for native-only value, loads the current wallet policy, and derives the role of a shuffled ordinary output from its authenticated receipt. The rerun used the same newly mined funding history, separate owner namespaces and fresh proofs and signatures. [Correction](../wallet/owner.py)
