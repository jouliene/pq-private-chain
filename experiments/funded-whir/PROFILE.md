# Funded WHIR comparison profile, version 1

The question is whether a verifier-owned relation over the existing funded note format can serve both transfers and swap legs. The live devnet continues using MNG1 and SLG1. Mint and burn use MNG1. The research evaluation uses the funded-note games and 128-bit quantum-work target in [the target registration](../spend-proof-decision/TARGET.md).

**Registered before candidate proving.** Goldilocks with the degree-five extension, 19 outer rounds, 2^18 main words, four independent subfield guards on every actual private scalar, three four-round folds, then a masked terminal linear form. Main widths are 16384, 1024, 64 and 64. Auxiliary widths are 8, 5, 3 and 37. Code lengths are 2^19, 2^17, 2^16 and 2^17. Query counts are 53, 38, 30 and 31. Each leaf has an independent pseudorandom 64-byte salt. Separate SHA3-512 trees authenticate the main and blind terminal openings at the same 31 sampled positions. SHAKE256 supplies coin streams and seeded wallet randomness. Each registered program binds its domain, profile and exact public matrix. The verifier checks a canonical public field vector, rehashes both ordered receipts with the released Poseidon2 byte convention and consumes the proof to EOF. Four guards apply to the full private vector, which includes gadget intermediates. Unused padded columns have zero weight.

**Decision gates.** The non-author's numerical screen gives about 130.9 bits of conditional interactive error exponent and about 65.45 bits at the order-one quadratic loss of an ideal compiler. These are bounds used to assess a proof, not measured attacks. The general proof-of-knowledge reduction and joint noninteractive privacy proof for this exact protocol, including receipts, are open. Genuine research proving is useful for compatibility and frame sizing. Passing does not activate the candidate in consensus. A separately calculated stronger schedule has an expected proof-only payload above 480 KB. It requires its own proof of correspondence. The independently derived individual round terms, assumptions and frame bounds are in [the parameter calculation](review/profile.py). [Constrained-code protocol](https://eprint.iacr.org/2026/391) · [ideal quantum compiler](https://eprint.iacr.org/2019/834)

The 262,144-byte cap applies to each complete physical frame, including ciphertexts, public words, the swap header and each 17,088-byte signature. Both wallets must authorize the digest over the final proof-bearing legs. The local trial uses a distinct experimental encoding and makes no chain activation or historical conversion.
