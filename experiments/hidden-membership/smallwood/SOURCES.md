# Sources for the SmallWood+ implementation

The primary source is Feneuil, Provin and Rivain, *Sum-Checking SmallWood: Smaller Hash-Based Zero-Knowledge Arguments*, IACR ePrint 2026/2880, updated 12 November 2026. The primary site's PDF returned HTTP 403 to this environment. The public ePrint mirror supplied the full PDF with SHA-256 `6a650832d5f90e5a9f09c56857851cbbb22eb2116ae25ff30d8d716ab899bfec`. Section 6, p. 48, describes the authors' SageMath proof of concept and lack of representative implementation timings. Section 6.2 and Table 1 give the Keccak CICO statement and size estimates. Each permutation uses a public 256-bit prefix on both input and output. FS01 instead pins domain, level, padding, capacity, private selection, a hidden linked digest and a 512-bit terminal result. A measurement for an independent permutation batch does not account for these constraints. [Author preprint](https://eprint.iacr.org/2026/2880) · [Full PDF mirror](https://eprint.iacr.asia/2026/2880.pdf)

The public CryptoExperts organization contained two SmallWood repositories. The public branches in each had one head. The C implementation covers the 2025 construction and CAPSS. The Python/Sage prototype includes DECS, PACS and multilinear PCS interfaces, tied to the previous SmallWood IO protocol and its commit/open schedule. The 2026 Compiler 1 adds a single commitment to witness and trace masks, the masked SC-IP, a challenge-derived SVCS, trace linearization, SmallWood-LCS and finally its degree/opening checks. A previous multilinear PCS alone does not implement those steps. The implementation here independently follows Figures 4, 5, 6, 8 and 13 and Remark 7. It imports no predecessor source. The specialized CICO round reduction of §6.2 and the generic R1CS route in §6.1 are different instantiations. The GitHub public-repository and branch listings, name search for SmallWood+ and the public accounts identified as Thibauld Feneuil and Killian Provin yielded no released code for 2026/2880 on 22 November 2026. The paper contains no repository link for its SageMath implementation. This records the search frontier on that date. Obtaining that release would enable a separate compatibility check against the application-specific Keccak proof and the paper's reported geometry.
