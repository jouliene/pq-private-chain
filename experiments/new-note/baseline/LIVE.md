# Funded note security boundary at ceab1e4

MNG1 and SLG1 are distinct registered Plonky2 verifiers over the same funded AST1 note commitments and real nullifiers. Both verify a spend under an eligible anchor. Their private path length can differ from the depth of the node's selected funding tree. Their parent, note and authority functions all use four-word digests. This baseline supplies no 128-bit post-quantum funded-binding or spend-knowledge guarantee. Replacing only the proof engine or only the tree would retain independent four-word assumptions. The released registrations stay available for the local research devnet. [MNG1 profile](../../managed-assets/native/profile.rs) · [SLG1 profile](../../atomic-swap/native/profile.rs)

## Membership games

A funded safety game fixes a previously accepted branch or lets the adversary choose among *eligible* branches, and asks whether a real-slot witness represents an authorized occurrence under the chosen header. A preselected honest note, a fixed honest parent, two attacker-chosen messages or roots, and a branch containing attacker-funded chosen leaves are different experiments. An arbitrary pair of colliding parent inputs alone supplies neither the private opening of an existing honest commitment nor authority to spend it. Conversely the registered verifier's admissible siblings are wider than independently funded subtrees. A security argument may not restrict an adversarial path to wallet-generated, byte-sorted siblings. Reusing one untagged parent domain at every level and feeding commitments directly into the path also requires treating depth/leaf interpretation explicitly. The absent count check by itself proves no successful theft.

Let p = 2⁶⁴ − 2³² + 1. The deployed parent absorbs two ordered blocks of eight fields followed by the fixed 1,0,…,0 padding block into a width-12 additive Poseidon2 sponge. It uses three permutations with four capacity words and outputs the first four rate words. The closed FTL1 parent uses a tagged capacity IV and two absorptions, with the same capacity and truncation. The original node's sorter does not occur in either adversarial opening predicate. FTL1 additionally commits to the selected branch block ID and n in its Fiat–Shamir context and verifies an additional public four-word root, while the original d remains private. [Pinned Poseidon2 crate, including padding](https://docs.rs/crate/qp-poseidon-core/3.1.0/source/src/lib.rs) · [Base path](https://github.com/DigitalGuards/qnero/blob/f04c91307837c0231668383bec76ba98d89d2652/crates/qnero-circuit/src/merkle.rs#L60) · [FTL1 branch verifier](../../funded-tcith/node/registration.py) · [FTL1 structural review](../../funded-tcith/security/REVIEW.md)

For a black-box random output space of p⁴, classical/quantum order-of-magnitude scales are p²/p^(4/3) for a freely chosen collision and p⁴/p² for a single random target preimage. These correspond to approximately 128/85.33 and 256/128 bits of queries. An ideal *public permutation* sponge can have a capacity-dependent preimage method even at a fixed target. The live parent has two unconstrained absorption blocks apart from the distinguished child, and a fixed final padding permutation before truncation. That extra known permutation changes the terminal map, while preserving its size and invertibility before truncation. Under the intermediate-capacity matching heuristic with sufficient free input and output coordinates, the same four-word capacity scale is about p^(4/3) quantum, p² classical. The known padding block is no justification for promoting this application to an ideal 256-bit random function. This is a model-based structural screen. Alagic et al. use bit strings, XOR absorption, a random permutation and its inverse, and explicitly distinguish a uniform target from an image of a random input. Their Theorem 2.2 is a probability upper bound for *that* game; the generic methods following it give query-cost upper bounds, with a gap. No tight lower bound for this field sponge, concrete Poseidon2 constants, or the chosen-branch funded relation follows. Coherent lookup and memory costs can be substantial. ## Authority, single consumption and lifetime

Write H(tag, …) for the domain-prefixed field sponge above. The wallet derives ask, nk and its receiving KEM seed under distinct labels from one 32-byte seed. The circuit accepts ask and nk as witnesses: their wallet seed derivation is outside the statement. It binds ak = H(AK, ask) and pk = H(PK, ak, nk). A note's effective r = H(OPEN, per-note ID, token value, raw). On SLG1 creation, raw itself is bound to the eight public key limbs and fresh randomness using SWAP_OPEN. A received leg note is subsequently spent with its recovered effective raw opening. For each real slot, the same pk, rho and r determine inner = H(NOTE, pk, rho, r), cm = H(CM, inner, native value), and nf = H(NF, nk, rho, r) with the same nk as pk. A dummy uses NF_DUMMY, zero values, and skips the root equality. Separate domain tags distinguish inputs to H but their *output spaces* overlap. An ordinary output derives rho = H(RHO, nf₀, nf₁, output slot); a mined AST1 reward derives rho and raw from the public reward body under separate reward domains. The recipient checks decrypted fields by opening the delivered commitment using its own spending-derived pk. Binding the same nk inside pk and nf prevents a straightforward free choice of nf for a given registered opening. Single consumption also requires computational uniqueness of valid openings under a funded cm and deterministic nf across every accepted spend route. Reopening cm with different credentials, type, value or effective randomness would be a different event from a coincidental equal nf between two distinct valid notes. The latter can deny acceptance to the later spend. Static pk may appear on many notes; wallet compromise or a credential preimage affecting that pk can expose the whole inventory. Public deterministic nullifiers deliberately link retries, reorg resubmissions and conflicting alternatives. A total of 256 seed bits is an upper bound on seed entropy. It is not an extraction theorem for finding *any* admissible credential pair for an exposed pk. The functions' shared permutation, differing tags, short/long input structure and correlated public openings require individual analysis; a multi-block parent's ideal structural exponent cannot simply be copied into every key or note function. A wider new tree by itself changes none of these leaf-level functions.

For T available target digests of similar distribution and a uniform isolated output space p⁴, the elementary many-target search estimate under a membership oracle is p²/√T quantum queries. T = 2²⁰ illustrative distinct live targets would reduce that *particular* ideal search exponent by 10. A passive observer cannot choose an arbitrary historical root as a currently eligible anchor. The number of outstanding notes/keys, eligible anchors, accessible internal nodes, adversarially funded subtrees and repeated adaptive attempts are different quantities. At per-attempt failure ε a union bound over M valid conditional trials is at most Mε, even with dependence when each bound holds given history. 100M annual offered payments is a sizing input and is neither T nor M by definition. Also distinguish total quantum queries, memory, parallel and wall-clock cost, compromise of a reused seed, and a reduction's loss over two legs and many proofs. The corresponding lifetime game must cover backup-only reconstruction, spentness on the current branch, offer/retry linkage and access to correlated historical receipts. A new note pool needs its own leaf/internal/level domains and canonical path semantics, verifier-authenticated anchor/root/depth/count as required by that design, a stated ownership/one-nullifier binding game, and an explicit cutover rule. An old registration left able to debit the same new value would remain a route for its old assumptions. An isolated devnet retaining legacy funds and auditing legacy liabilities can state those assumptions separately. No changed registration, new funded transaction or security qualification is claimed by this source and wire audit.
