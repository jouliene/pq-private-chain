# D8C1 preregistration

The inner program is the published DLF1 blinded direct spend verifier at SHA-256 `5d6cfc6ccff5792e4899799124b2fb1e7dac50f727825c4886485dc01a564ce8`. The outer program instantiates eight constant-key recursive verifiers for precisely that circuit. Before creating any certificate, derive and pin the outer verifier from source. Both layers use Goldilocks D=2 with two challenges, 128 configured security bits, 135 wires/60 routed, rate exponent 5, 26 FRI queries, grinding 0, cap height 4, fixed two-bit reductions with final-degree parameter 3, and the following layer-specific hiding flags. The inner keeps row blinding and hiding FRI leaves. The outer sets both off. Its complete witness (the public DLF1 proof bytes, flags, and repeat-last padding) is derivable from the already transmitted direct packets, so no new wallet opening or secret enters the recursive prover. Archival compaction does not erase previously transmitted packets, or provide a theorem that an observer receiving only the archive learns no property of those public proof encodings. These parameters specify a concrete experiment and do not establish post-quantum knowledge soundness or privacy.

The outer public inputs are the D8C1 domain (0x443843310001), real count and eight ordered full 26-field DLF1 statements. Eight Boolean flags form a nonempty active prefix. Every inactive slot has the preceding slot's statement. Every proof, including padding, verifies against the same constant direct key. The builder repeats the last genuine public proof as needed. Network framing is D8C1 || u8 real count || u32le proof length || canonical proof || two complete 1,792 B ciphertexts per real slot. The verifier cross-checks the count, repeated public input tails, distinct real nullifiers and commitments, receipt codec/digest, fee and exact framing. Individual block state checks still evaluate original anchors, spentness and effects at the named historical heights.

The preliminary implementation used the same hiding flag for both layers. The primary non-hiding outer was selected before registration or proving; there is no earlier hiding-outer proof in this experiment.
