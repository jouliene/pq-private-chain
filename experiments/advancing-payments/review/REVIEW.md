# Independent advancing-payment review

The starting revision is `cc2d9b9e6b6e5d4cbcd7e241f0025dc20c84b963`. The owner sizes the system for 100M offers per 365 days. Offered work, accepted transaction count and package occupancy must be reported separately. The development ledger uses an eight-block selected-branch anchor window and typed native packages of one to four payers.

## Checks registered before the execution freeze

- Rebuild the accepted funded root with the unmodified upstream full tree from the ordered public commitment sequence. Check growth past 4, 16, 64 and 256 leaves. Sorting follows canonical serialized digest bytes and padding is the all-zero digest at each incomplete level. In a separate public control, permuting two siblings leaves the upstream funded root equal. Distinguish same-height branches by parent and ordered state/body identity. Check the canonical header and state again after a rollback and after process restart.
- The prospective block height H permits an anchor at h precisely when `1 <= H-h <= 8` and the anchored ID belongs to the selected history. Spend eligibility uses current nullifier and commitment indexes plus earlier slots in the same atomic block. A retained historical funding proof alone cannot establish current spentness. Different wallets in one aggregate may anchor at different eligible heights. Check exact height edges, expired and orphaned anchors, and availability of earlier unspent funds through a fresh eligible path. Distinguish an anchor shared by both branches from an orphan.
- Compare all retained database tables prospectively with a replay from approved genesis after competing suffixes, including body ordering, spent nullifiers, funded commitments, redo/undo bounds and ring/frontier entries. An invalid later step in an attempted reorganization must leave the former branch intact. Pruning removes reconstructible old material while preserving lifetime uniqueness and current spentness, current funding root, all acceptance-eligible anchors and any rollback information promised by policy.
- Measure 1/2/3/4 genuinely occupied transfer packages with independent wallet processes and genuine wallet/outer verification. Check every publicly forwarded anchor, height, fee, nullifier, output commitment and ordered ciphertext against the corresponding standalone wallet packet. Only a wallet can report both real private inputs and receipt openings; alternative endpoints and the node must not receive the inputs, nonhiding leaf proof or note openings. A selected recipient should spend newly received notes under the advancing ledger.
- Measure queue eligibility age, time from payment arrival to inclusion, waiting policy and service at low load and on builder loss. A successful transport handoff does not establish timely inclusion. Replaying a packet after an ambiguous endpoint response must yield a single economic effect. Count retries/stale proofs and all fallback traffic, preserving original offer denominators. Include any extra occupancy-independent per-block costs and any unfilled portions of the stronger proof.
- Check limits on wall-clock claims against the anchor window. To include 100M payments per year consistently at occupancy four, even without empty blocks, the minimum rate is about 0.7927 blocks/s, leaving roughly 10.09 s across eight produced blocks at uniform spacing. At mean occupancy two the analogous time is 5.05 s. Real block spacing has a distribution. Compare wallet preparation, queueing, sequential builder service and inclusion with the actual elapsed age and number of blocks; distinguish stable archived verification from sustained live payment viability.

The [reference oracle](reference_roots.rs) calls only the upstream `CommitmentTree::new` and `depth_for` from Qnero revision `f04c91307837c0231668383bec76ba98d89d2652`. [Initial public vectors](REFERENCE_ROOTS.json) contain synthetic canonical commitments derived by setting word j of leaf i to `731*i+j+1`, with both indexes starting at zero. At 260 leaves, a sibling swap preserved the reference root and a cross-quartet swap changed it. These vectors establish the independent comparator before the candidate state code is tested.
