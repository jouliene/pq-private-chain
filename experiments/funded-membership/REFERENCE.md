# Funded note membership, ownership and one-spend identity

The monetary statement is existential. At the selected anchor there was a funded occurrence of the **same** note that the spender opens and controls. The published nullifier is determined by that opening and its authority, and it is unused in the current branch immediately before admission. Absolute chronology inside a group of siblings is unnecessary for this statement.

Run the independent reference from the checkout root with `python3 -IB experiments/funded-membership/vectors.py`. The checked-in public answers contain synthetic fee-funding, managed and swap-output commitments and nullifiers. The reference has no prover, proving keys, receipt decryption, network access or dependency on an installed deployment. ## Funded tree

Use the selected branch's append sequence. A block appends both commitments in each accepted physical slot's order, then its reward commitment. Leaf bytes are already the commitment. Each digest is four canonical little-endian u64 elements of the Goldilocks field with modulus 2⁶⁴ − 2³² + 1. Reject encodings at or above the modulus instead of reducing them. Reject zero and duplicate commitments in the funded sequence. The maximum population is 4²⁰. Compute the tree as follows.

1. An empty sequence has root 32 zero bytes and depth zero. A sequence of size one through four has depth one. In general the nonempty depth is the smallest positive integer d with count ≤ 4ᵈ.
2. Partition each current row into consecutive groups of four. Pad the last incomplete group directly with the all-zero digest. An entirely absent subtree contributes zero at its current level. Do not recursively hash an empty quartet to manufacture padding.
3. Within each group sort the four serialized 32-byte strings in ascending lexicographic byte order. Decode each into four field limbs, concatenate the 16 words and absorb using the funded Poseidon2 sponge. The resulting four words, serialized little endian, form the parent. This existing parent has no domain or level prefix. Keep the order of the resulting groups in the next row. Apply exactly d levels.
4. A canonical path has three sorted siblings and a sorted insertion rank at every level. For an equal running digest the wallet encoder selects the first equal rank. This convention chooses bytes for an honestly encoded path. It adds no order commitment. Swapping children within a group preserves the group hash. Moving a child into a different group generally changes the root.

The oracle receives the complete authenticated sequence from the current branch's validated anchor, an opening and a private occurrence index. It compares the opened commitment directly to the history at the index, derives its canonical path from that history, and reconstructs the root at the exact depth. This full-history predicate defines the desired property without assuming that every root-equal path corresponds to an actual funded leaf. The index resolves a witness locally. It cannot be recovered from within-group order in the root. A public node evaluating a private proof does not receive the input opening or index. ## Note and authority

Let H hash a sequence of canonical field words. It starts with twelve zero field elements, appends field 1 to the message, then pads to a multiple of eight with zero words. Each block adds to the first eight state elements and applies the pinned Goldilocks Poseidon2 permutation. Return the first four elements. Byte-mode H appends byte 0x01, zero pads to a multiple of four, decodes u32 little-endian limbs and hashes them with the same field framing. Public mathematical constants are copied from qp-poseidon-core 3.1.0 `src/poseidon2.rs`, SHA-256 `54604af022354364c45fbdde106be3f223775992d6fa5685e77c75e66fd970f6`. The reference computes the permutation numerically, independently of the prover's gates. [Round parameters](reference_constants.json) · [Parameter license](reference_constants.LICENSE)

The funded equations use domain tags AK, PK, NOTE, CM, NF, RHO and NF_DUMMY in consecutive order from 0x716e0001 through 0x716e0007. A digest expands to its four field words at every concatenation.

- The authority opens `pk = H(PK, H(AK, ask), nk)`. The account seed can derive both private words, but monetary authorization needs the preimages associated with the note's actual pk.
- Both native and token quantities are integers in [0, 2⁶²−1]. A positive token quantity requires a nonzero asset ID. Zero tokens use the zero ID. Each of the four serialized asset limbs is below 2⁶³. The typed opening is `r = H(0x415354310001, asset_id, token, raw)`.
- The committed note is `cm = H(CM, H(NOTE, pk, rho, r), native)`. Its real spend ID is `H(NF, nk, rho, r)`. The formula for a given funded input is the same in both proof eras, at all eligible anchors and under all actual output choices. In particular this identifier is independent of the chronological index. The construction's binding, preimage resistance and absence of problematic collisions remain cryptographic assumptions.
- Fresh transfer outputs derive `rho = H(RHO, nf0, nf1, output_slot)`. Swap creation additionally computes the effective raw opening using `H(0x534c47310001, eight u32LE signing-public-key limbs, raw)`. A subsequent recipient spends the effective raw as an ordinary opening. The consensus authorization for the pair of swap legs and the issuer's authorization for registry events are distinct from the recipient's spending authority.
- A reward note uses byte-mode H over the literal ASCII tags `AST1/reward/rho` and `AST1/reward/raw` concatenated separately with the reward context, miner pk, native u64LE and zero token u64LE. The block layer independently derives the reward context, amount and issuance source.

## Admission and scope

Each logical input pair has exactly two slots with at least one funded input. A swap leg requires a real first input. A dummy has zero native and token value, carries no fundable occurrence or path in the oracle, and publishes the separately tagged `H(NF_DUMMY, nk, rho, r)`. Authenticated real notes may carry zero native value and positive managed assets. The two submitted nullifiers must differ and both must be absent from the current selected spent set. The oracle returns a new immutable union only after every slot passes. An earlier valid anchor never rolls current spentness backward.

The `selected_inputs` adapter receives an already verified current-branch header index and spent set. It checks exact selected height and identifier and the released inclusion interval 1 ≤ candidate_height − anchor_height ≤ 8. The full node owns PoW, map construction, exact supply, conservation, fees, atomic block writes and reorganization. This narrow witness predicate cannot validate payments by itself. The full-chain scenario exercises those independent duties.

The synthetic controls check branch membership, wrong authority, opening drift, zero padding, amount and asset bounds, cross-slot reuse, spent-after-anchor, detached anchors, stale anchors, zero-value dummies and atomic rejection. Known roots computed by the pinned upstream full tree include 1 through 260 leaves at boundary sizes. The size calculation checks capacity 4²⁰ without allocating a trillion leaves. This suite does not decide cryptographic knowledge, root binding, joint privacy or quantum security. [Vector results](vectors.json)
