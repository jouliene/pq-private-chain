**The first amplified opening already exceeds the signed-leg proof allowance.** At the selected security screen, the initial check opens 495 right vertices, two interleaved rows per vertex, eight neighbors per row, and 40 bytes per underlying field value. A concrete SHAKE256 query draw therefore needs **316,800 bytes for values alone**. The complete worst-case projected proof is **1,172,088 bytes**. No funded proof was generated for this excluded profile. The model, graph arithmetic, coin draws and actual multiproof frontier counts are executable. ## A reproducible graph and its distance

Use the bipartite incidence graph with both sides indexed by G⁷, where G = GF(8) with reduction polynomial X³+X+1. Write the right label as (a,b₁,…,b₆) and the left label as (x,y₁,…,y₆). The eight neighbors, in ascending x, are given by yᵢ = bᵢ + a xⁱ. The first component is the least significant base-eight digit of the integer label, followed by components in increasing order. Each point has one incident right vertex for each a. Both sides have N = 8⁷ = 2,097,152 vertices and degree d=8, with no repeated neighbor. The graph has no random parameters or setup failure. Its label field is separate from the proof field.

For dimension s+1 and label field of size d, let B be the unnormalized incidence operator from the right side to the left side. The additive characters on right vertices have the form χ(a,b) = (−1)^Tr(ua + Σvᵢbᵢ). To apply BᵀB, sum first over a neighbor parameter x and then over the slope a′ of a right vertex incident at that same point. Orthogonality of additive characters leaves dχ(a,b) for each x solving u + Σvᵢxⁱ = 0, and zero for the other x. Every nontrivial character therefore has squared *normalized* singular value at most s/d when s<d. The constant character has eigenvalue one. A degree-s polynomial with s distinct roots shows the bound is attained. The check enumerates the entire 64-character spectrum for dimension two and constructs a degree-six polynomial attaining 6/8 for the selected graph.

Let an agreement set on the left have fractional size ε, and let T be all right vertices with every neighbor in that set, of fractional size t. The mean edge density from T into the agreement set is t. Removing the two constant components and applying the singular value bound gives t(1−ε) ≤ λ√(ε(1−ε)t(1−t)). Consequently t ≤ γ = λ²ε / (1−ε+λ²ε). This proves the CFW §13 disperser condition, including arbitrary adversarial left sets. For the selected masked RS degree 135,098, ε=135098/2097152 and γ=67549/1375585. The amplified code has tuple-alphabet relative distance at least 1−γ. This is a design-specific certified distance; the actual distance may be larger. CFW Proposition 13.4 instead gives a probability bound for randomly sampled graphs. This instance needs no assumption about any public seed representing such a graph. [CFW §§13.1–13.3, pinned PDF SHA-256 472f52b29d65d898c6b0dc9854ff4a25928467a14133eb77be5ca60357c2a0b1](https://eprint.iacr.asia/2026/391.pdf)

## Oracles, challenge fields and privacy

Both profiles retain the independently registered funded matrices, complete public statements, note/receipt derivations, and separate per-owner swap signatures. The projected proof replaces only the proof transcript. Its relation field is Goldilocks F, p = 2⁶⁴−2³²+1. Proximity polynomials, all inner/outer sumcheck coefficients and folding/zero-evader challenges use E = F[X]/(X⁵−3). A canonical E word has five u64 limbs, hence 40 bytes. The independently sampled source-subfield guard points and masked guard replies use F. Every RS access at integer i evaluates at ωⁱ, with ω = 7^((p−1)/N) in F embedded into E. All selected domain sizes have this precise order. Graph positions are uniform independent right indices sampled **with replacement**. Each opened initial tuple includes all eight RS positions for each interleaved row. Plain stages use one scalar per row per position. The seven guarded public replies cover all source words behind the first root, with one fresh base blind each. The 128 initial auxiliary words accommodate the three outer-terminal masks, 100 outer mask coordinates and seven blinds. [Funded verifier](../../funded-whir/proof/src/main.rs) · [Guard, sumcheck and source projection](../../wallet-created/structured/outer.rs)

Each stage uses a salted, binary SHA3-512 tree and a fresh 64-byte salt per *right* leaf. For t tuple queries the strong RS encoding needs privacy for up to d·t base positions per row, even if the joint query set is nonuniform on the RS domain. Each row therefore begins with r=d·t+1 independent E seed coefficients. Distinct rows have independent seeds. For any fixed base read set of size at most d·t, the Vandermonde map of the low coefficients has full rank, including after fixing the message and spare mask coordinates. Repeated base locations return consistent evaluations. The extra coefficient retains one dimension beyond the covered reads; the model also retains the explicit salts. A fresh row polynomial has maximum degree main+aux+spare+r−1. This increased degree feeds back into distance, list and query estimates. Merely changing the query count while retaining the old masks would underprice the proof and leave the privacy argument incomplete.

For each nonterminal fold of k variables, keep two spare coefficients per row and 2(k+1) fresh global E mask coordinates in the degree-three sumcheck. After folding, carry the full previous auxiliary block, both spare coordinates and all r seed coefficients into the next encoded message. Fresh OOD randomness pads the resulting length to a multiple of the next interleave, with at least one fresh coordinate. The folded source code switch now tests **d·t** component equations in addition to the original target and one OOD equation. This is the w=d case of Theorem 9.12, keeping the linear form and scalar sumcheck module M=E; the code alphabet becomes Mᵈ. Its batching polynomial has degree at most 1+d·t. The following stages use w=1. This is an explicit proposed composition of Theorem 9.12 stages and a terminal Construction 7.2; the width-one specialization of Theorem 10.2 cannot simply be quoted for a changed transcript. For a binary tree of size N and q distinct queries, the maximal frontier is 2−q+Σ min(2ʲ,q) for 1≤j<log₂N. The bit-reversals of 0,…,q−1 occupy exactly min(2ʲ,q) prefixes at every level. The executable counts their actual siblings level by level. In stage zero these right vertices all have a=0, so the neighbor sets are disjoint. Even pooling repeated underlying base symbols across authenticated leaves saves zero of the 3,960 required evaluations on that configuration. A separate public SHAKE256 coin-seed fixture produces 495 distinct right locations using the funded u64LE sampler; its value payload alone is 316,800 bytes. The ideal independent interactive draws have probability at least 0.94169 of **all** 495 being distinct, via the elementary collision union bound. The bit-reversal configuration describes valid verifier coins. The SHAKE fixture exercises the sampler; it is not a Fiat–Shamir preimage search or a measured funded proof.

Adding the full envelopes gives 1,175,929 bytes for an ordinary transfer, 1,193,148 for one signed leg and 2,386,309 for a two-leg submission at worst case. These projected packets exceed the live frame limit. The model counts 849 authenticated leaf reads across six roots and a maximum of 11,595 leaf-plus-interior hash evaluations for the multiproofs, excluding tape, matrix and ordinary settlement work. Initial commitment construction across all six trees would involve 6,160,378 leaf-plus-parent hash calls. All committed scalar payloads sum to 1,814,036,480 bytes before salts or internal digests. This is an encoding-volume count, not a peak RAM measurement; a prover may stream evaluation data. The verifier still binds the appropriate public 15.2–15.6 MB matrix and applies the inherited sparse matrix/outer reduction as well as the neighbor generator equations. CPU, peak RSS and full proving latency were not measured for this candidate. ## Error and quantum compiler screen

The primary stage uses the elementary **generic additive-code MCA** statement of CFW Appendix A.1. Set D to the largest integer with 3D < (1−γ)N, and δ=D/N. Here D=664,723, the list size is one even for an interleave (the balls are inside half the distance), and the MCA error coefficient is at most D+1 over |E|. The per-query agreement is 1−δ = 0.68303537. This is materially different from using γ itself as the miss probability. The §13.3 example is a unique-pair spot check on a committed codeword. The funded proximity reduction also needs an MCA/list radius for adversarial words. For the unamplified RS tail the model retains the funded Johnson/MCA assumptions with additive slack 1/128 and rounds the square root upward to the next multiple of 2⁻⁴⁰. The tabled t is found jointly with the enlarged RS seed/degree until each miss term is at most 2⁻²⁷². [CFW Theorem 9.12 and Appendix A.1](https://eprint.iacr.asia/2026/391.pdf) · [Inherited RS field/list estimate](../../funded-whir/review/profile.py)

For each k-folding stage the conservative aggregate includes (2ᵏ−1) base MCA coefficients, (1+2k) current list factors for low-degree checks, the next squared list size times the OOD collision bound, and the next list size times (1+d·t)/|E| for scalar batching. The terminal check contributes its MCA term plus list/|E| and a separate miss term. The outer guarded map, masking polynomials and terminal mixing errors use the same degree and field bounds as the funded estimate with seven base guards. The guard is bounded by L₀(2¹⁸/p)⁷. The overestimate of aggregate interactive error has negative log₂ 267.875 conditional on the source correspondence. Its components have exponents 322.000 for the guard, 267.995 for field/list algebra, and 271.523 for aggregate misses. The generated evidence retains the per-stage list bounds, MCA coefficients, rates, query counts and lengths.

In the ideal CMS single-instance sensitivity with unit hidden constants, t²κ reaches one near 2¹³³·⁹⁴ quantum oracle queries; the cubic term t³/2⁵¹² reaches one near 2¹⁷⁰·⁶⁷. At t=2¹²⁸ the quadratic term is about 2⁻¹¹·⁸⁷⁵. A conservative union of 100 million per-instance bounds at the *same per-instance query budget* gives an order-one crossover near 2¹²⁰·⁶⁵. This sensitivity does not model an optimal adversary sharing one global query budget. The theorem also charges O(q log ℓ) verification queries, has hidden constants, assumes the particular BCS construction and an underlying round-by-round knowledge extractor, and states an additive extraction loss. The existing labeled SHA3-512/SHAKE256 transcript, parameter binding, challenge packets, multiple adaptively chosen statements and coupled receipt encryption need a source-specific composition argument. No end-to-end 128-bit claim follows from the projected scalar budget. [CMS Theorem 8.6](https://eprint.iacr.org/2019/834) · [Funded source-assurance obligations](../../funded-whir/review/GATE.md)

## Sensitivity and scope of the exclusion

Holding the amplified stage fixed, an 81-point grid over four unamplified tail domain sizes keeps all trial interactive exponents above 260 bits. The smallest worst case in that grid is **1,129,744 bytes**, with tail log₂ sizes (21,19,18,19), query counts (495,72,60,53,51) and 147 terminal coefficients. Moving the only amplification to the final switch expands its large seeds into an unamplified terminal message of 4,455 coefficients and costs 1,243,200 bytes. Giving the amplified stage an optimistic tuple-Johnson radius while omitting its missing MCA theorem yields 643,112 bytes; the model deliberately has no aggregate security number for that sensitivity. Plain RS at the same initial two-row width and original tail domains is 582,376 bytes. A 132-bit per-stage miss screen yields 595,320 bytes and about 131.23 conditional interactive bits, insufficient for the quantum quadratic-loss screen. [All sensitivity cases and query counts](MODEL.json)

There is a schedule-independent obstruction **within this incidence family, under the selected Appendix A.1 correspondence**. Even a perfect code distance permits δ only below 1/3 under that lemma. Getting a single miss term below 2⁻²⁵⁶ consequently needs at least 438 amplified queries. Degree two or four cannot accommodate the required seeds in this family: s<d forces N=dˢ⁺¹≤dᵈ≤256, yet d·438+1 already exceeds that domain. Every admissible remaining degree is at least eight. A nonterminal stage has interleave at least two; a terminal stage must open two separately committed scalar oracles. With sufficient distinct positions, their explicitly authenticated value fields alone can therefore occupy at least **438×2×8×40 = 280,320 bytes**. The exact primary exposes 316,800 value bytes before any hashes. This justifies stopping before funded proving. A different disperser, certified stronger decoding/MCA, different authentication and masking scheme, or different word encoding would require its own calculation. The funded chain retains its existing spend and swap registrations.
