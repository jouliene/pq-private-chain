# Fixed-parent SLG1 packed TCitH proof

The native executable proves and verifies the complete 38-word fixed-parent SLG1 relation. Its verifier authenticates one 3,717,289-byte public circuit by SHA-256 before parsing it. Its private input consists of the 16,818 assignment coordinates after the public columns. It derives all quadratic and seventh-power ports from the registered affine forms. ## Build and role boundary

From the repository root, choose a new public output directory, the pinned Poseidon constants from the predecessor reproduction, and execute the following commands.

```sh
c++ -std=c++17 -O3 -Wall -Wextra -Werror experiments/funded-tcith/proof/engine.cpp -lcrypto -o "$out/tcith"
python3 -IB experiments/funded-tcith/proof/register.py "$constants" "$out/shape"
python3 -IB experiments/funded-tcith/proof/smoke.py "$out/tcith" "$out/shape" "$constants"
```

The owner process supplies binary standard input to `tcith prove SHAPE` and reads a bare proof on standard output. Input is 32 bytes of locally reconstructed public context, 38 public Goldilocks words and exactly 16,818 private Goldilocks words. The wallet must keep this private input in memory and use a pipe. Core dumps are disabled. A separate process runs `tcith verify SHAPE` with only the same 336-byte public prefix followed by the bare proof. Its exit code is zero on acceptance. Role I/O is bounded before proof parsing. The verifier needs no prover service, randomness file, secret polynomial or party data. Each verification reconstructs both monetary broadcasts. The surrounding branch and wallet roles derive the context, authenticated root, public effects and receipt projection, and handle eligibility, signature, fee policy and atomic spentness. The local shape compiler uses the frontend's blank assignment to emit the public shape. It has no role in public verification once the pinned shape is available.

## Registered transcript

Every field word and scalar index uses eight bytes, little endian. Field words at least p=2⁶⁴−2³²+1 are invalid. The suite digest `U` is SHA3-512 of the following concatenation in order.

1. ASCII `FTL1/TCitH-MT/SLG1/Goldilocks/fixed-parent/fft256/v1` and one zero byte.
2. The raw 32-byte SHA-256 of the verified shape, hex `77533cc1c383bec78358ae8b304a1151aab834c34656d2edcc167dccdaf1c339`.
3. The eleven u64 registration words (262144, 256, 117, 32, 148, 5, 33, 450, 10, 533, 7).
4. The 336-byte public prefix.

Write H(t,data) for SHA3-512 over ASCII byte t, U and data concatenated. For challenge streams concatenate 4,096-byte SHAKE256 output blocks. Each block absorbs an ASCII stage byte, U, all preceding stage digests in chronological order and a u64 counter starting at zero. Field streams drop 64-bit little-endian samples at least p. To draw party indices, take the low 18 bits of successive unfiltered uniform u64 samples and ignore duplicate indices until the set has size 32. All opening serialization uses ascending indices. The public verifier derives every challenge.

Let g=7^((p−1)/262144). Party index i maps to g^(floor(i/256)+1024·(i mod 256)). The 117 secret points in increasing slot order are 7·g^j for j=0…116. The 256-point cosets let the prover process 533 short transforms per tile without allocating the 1.12 GB table. For each of the 450 packed witness columns, interpolate at all 117 secret points and 32 additional party points (indices 0…31). Draw the latter values independently and uniformly by rejection sampling OpenSSL RAND_priv_bytes. This bijectively samples all degree-at-most-148 polynomials extending the witness slots, including for parties that happen to coincide with these interpolation points.

The packed groups contain W, A, B, C, X, Y in that order. Each group pads independently with zero to a multiple of 117, yielding 144, 18, 18, 18, 126 and 126 packs. The fixed program's 102 linear rows contribute their affine equations directly. Each nonlinear operand creates one equation `form(W,public) − port = 0` in program/operand order. Then each of the 271 padding coordinates contributes its own one-term equation in group/coordinate order. This gives 35,934 global rows. Use 144 independent nonlinear batch coefficients, one per packed quadratic block followed by one per packed seventh-power block.

After the witness columns come five sets of ten hint polynomials and 33 degree masks, sampled in monomial coefficients uniformly through degree 148. Within each group of ten hints H₀…H₉, the polynomial mask is Ω₀(X)·Σ X^o Hⱼ(X), where Ω₀ vanishes on the secret points and the eight offsets o are 0,117,234,351,468,585,702,771. The linear mask is H₈(X)+X¹¹⁶ H₉(X). Before commitment subtract its secret-point-value sum divided by 117 from H₈'s constant coefficient. This uniformly samples the linear hints conditioned on sum zero. Independent randomness generates every leaf's fresh 32-byte salt. The implementation uses the operating system–seeded OpenSSL private DRBG; no caller-supplied seeds enter proof generation.

1. Leaf i is H(L, i || salt || 533 ordered canonical field words). Internal heap node j is H(N, j || left || right); leaves have heap indices N+i. Commit as h₁=H(R, tree root).
2. From G, h₁ draw the 33-by-500 row-major degree projection Γ. The 33 polynomials ξ equal Γ·(witness and hints)+degree masks. Set h₂=H(X, table), serializing the first 149 party evaluations in increasing index, then degree-mask order within each evaluation.
3. From B, h₁,h₂ draw five groups, each 144 nonlinear block weights followed by 35,934 affine row weights. Aggregate the registered affine rows with those weights. Interpolate each resulting private-coefficient pack on the secret points. The linear broadcast is the sum of the pointwise products of these public coefficient polynomials with the corresponding witness packs, plus its sum-zero mask. The public target is the negated weighted sum of constant and statement terms. The nonlinear broadcast is the weighted sum of A·B−C and X⁷−Y plus its polynomial mask. Hash h₃=H(A, table), serializing for each batch, in order, its polynomial broadcast at the first 1,037 party points then its linear broadcast at the first 265 party points.
4. From I, h₁,h₂,h₃ draw 32 opened indices. Send h₁,h₂,h₃, then the 32 salted rows, then the Merkle siblings in increasing heap index per level, bottom up. Send ξ at every secret point in point-major order. For each batch send 888 polynomial evaluations at the lowest unopened party indices, 116 secret linear evaluations in slot order and 116 linear evaluations at the lowest unopened indices.
5. The verifier reconstructs the Merkle root. It computes ξ and both broadcasts locally at the open points. It interpolates ξ from the 32 checked and 117 transmitted values. It interpolates the degree-1,036 polynomial broadcast from the 32 checked values, 117 zero slot values and 888 extra point values. It derives the last linear slot as the public target minus the sum of the other 116 and interpolates the degree-264 linear broadcast from 32+117+116 values. It hashes the resulting canonical tables and compares all three digests. Every accepted proof consumes the entire input.

It realizes the predecessor's allowed multiplicative-subgroup variant, fixes the suite and hash encodings, samples witness polynomials by evaluation extension, and rebuilds the transmitter's exposed rows by Horner evaluation after coset FFT commitment.
