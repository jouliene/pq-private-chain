# TKN1 fixed pair payment registration

The private opening contains a native integer, one registered token integer, rho and raw randomness. Both integer lanes range from zero through 2^62−1. For each of the two inputs and two outputs the spend relation computes r′ = Poseidon2(0x544b4e310001, token, raw_r[0..4]) and connects all four digest limbs to the exact randomness wires of the existing authenticated note and nullifier relation. The inner note commitment binds (pk,rho,r′); the outer commitment binds that inner digest and native value. The nullifier binds (nk,rho,r′). Output rho derives from both input nullifiers and output index. Pre-registration revision before build or proof: one or two inputs may be real. Each real input must prove membership at the authenticated header root. The original boolean selector gates native value and the new identical multiplication gates token value: a dummy contributes zero to both lanes. A real-anchor payment needs at least one real input. A note may hold zero in one lane. Tests include two positive funded inputs, a zero-native token-bearing real input and a one-real-input transfer.

Token inputs sum to token outputs; native inputs sum to native outputs plus exactly three native units. Each side fits below the Goldilocks modulus, including the fee. The four token bounds, token equation, fixed fee and four typed openings are new constraints. Issuance is limited to an operator-approved synthetic genesis with fixed two-lane totals. There are no asset tags selected by senders, registry changes, fee-bearing tokens, mining emissions, bridges, or post-genesis issuance in this experiment.

The public statement remains 26 Goldilocks elements. The frame starts with TKN1. The native verifier recomputes the two-ordered-ciphertext digest and compares it with the independently verified statement. Each suite-1 encrypted payload carries native u64, token u64 in the old asset-id field, rho32, raw_r32 and a fixed-size memo. Consumers recompute r′ and the published commitment after decryption. The proof does not enforce correct encryption to the named payee or certify receipt deliverability. A distinct validator-owned verifier, synthetic genesis and TKN1-specific state/record domains define the isolated version.

The blinded direct spend circuit uses Goldilocks D=2, 135 wires/60 routed, two challenges, configured 128 security bits, rate bits 5, 26 FRI queries, cap height 4, no grinding, constant (2,3) arity strategy. Both circuit and FRI leaf blinding must be true. This is an executable experimental configuration with no new quantum knowledge, zero-knowledge or multi-user anonymity theorem. Registration precedes fresh wallet proofs. DLF1 and D8C1 have no activation on this chain.
